# SwasthTrack AI

Personal health and nutrition tracking foundation built with Next.js, TypeScript, App Router, Tailwind CSS, and ESLint.

This first milestone contains only application structure, responsive UI, reusable components, TypeScript health domain types, and isolated demo data. It does not include AI APIs, database integration, authentication, or external services.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Main routes

- `/` - Dashboard
- `/food` - Food tracking
- `/health` - BP and weight tracking
- `/medicines` - Medicine tracking
- `/reports` - Reports
